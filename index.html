    The story in one minute¶

    Java 8 gave us composable asynchrony (CompletableFuture, parallel streams, StampedLock, LongAdder), but every blocking call still tied up an expensive platform (OS) thread. So high-throughput services moved to reactive code, which scales but is hard to write, debug, and profile. Java 21 made virtual threads final: cheap, JVM-scheduled threads, so plain blocking code now scales like reactive code. Java 24 removed the biggest caveat: synchronized no longer pins a virtual thread to its carrier. Structured concurrency (preview) and scoped values (final in Java 25) finish the picture.

    Runnable examples live in examples/:

    • examples/plain-java: single-file programs you run with java File.java on JDK 21+.
    • examples/interview-coding: 21 self-checking interview solutions (./run-all.sh).
    • examples/tools-lab: a broken target service to practise diagnostics on, plus JMH, jcstress, and testing/static-analysis projects.
    • examples/spring-boot-vt: a complete Spring Boot service with virtual threads, a fan-out aggregator, bulkheads, scoped request context, metrics, and tests.
