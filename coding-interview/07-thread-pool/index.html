    7. Build a Thread Pool¶

    L3 ★★★ · worker loop · FutureTask · shutdown race

    Problem¶

    Implement a fixed-size thread pool with a bounded queue. submit(Callable) returns a Future. If the queue is full, reject. Support shutdown() (finish queued work), shutdownNow() (interrupt), and awaitTermination().

    The interviewer wants to see that you understand what ThreadPoolExecutor does: worker lifecycle, result and exception propagation, rejection, and the subtle race between shutdown and submit.

    Architecture¶

    flowchart LR C1[caller] -->|submit| S{shutdown?<br/>queue.offer ok?} C2[caller] -->|submit| S S -->|no / full| R[RejectedExecutionException] S -->|yes| Q[(ArrayBlockingQueue)] Q -->|poll 50ms| W1[worker-0] Q -->|poll 50ms| W2[worker-1] Q -->|poll 50ms| W3[worker-2] W1 & W2 & W3 -->|run FutureTask| F[(Future result / exception)]
    stateDiagram-v2 [*] --> RUNNING RUNNING --> SHUTDOWN: shutdown() (reject new, drain queue) RUNNING --> STOPPED: shutdownNow() (drain to list, interrupt workers) SHUTDOWN --> STOPPED: shutdownNow() SHUTDOWN --> TERMINATED: queue empty, all workers exited STOPPED --> TERMINATED: workers exited

    Code walkthrough¶

    State and worker creation¶

        private final BlockingQueue<Runnable> queue;
    private final List<Thread> workers = new ArrayList<>();
    private final Object stateLock = new Object();    // makes "check shutdown + enqueue" atomic
    private volatile boolean shutdown;

    public SimpleThreadPool(int threads, int queueCapacity) {
        queue = new ArrayBlockingQueue<>(queueCapacity);
        for (int i = 0; i < threads; i++) {
            workers.add(Thread.ofPlatform().name("pool-worker-", i).start(this::workerLoop));
        }
    }
    • Workers are platform threads named pool-worker-N. A pool exists to reuse expensive threads. (You never pool virtual threads.)
    • shutdown is volatile because workers read it without holding stateLock.

    The worker loop¶

        private void workerLoop() {
        while (true) {
            Runnable task;
            try {
                task = queue.poll(50, TimeUnit.MILLISECONDS);
            } catch (InterruptedException e) {
                return;                                // shutdownNow(): stop immediately
            }
            if (task == null) {
                if (shutdown && queue.isEmpty()) return;  // drained and no more submissions → exit
                continue;
            }
            try {
                task.run();                            // FutureTask captures exceptions into the Future
            } catch (Throwable t) {
                // a bare Runnable threw: keep the worker alive (a real pool would log this)
            }
        }
    }
    Code Why
    queue.poll(50, ms) rather than take() A worker blocked in take() would never notice shutdown. Polling with a timeout lets it check the flag regularly. The alternative is to put one poison pill per worker on shutdown.
    catch (InterruptedException) → return shutdownNow() interrupts workers, and that's the signal to exit immediately.
    if (shutdown && queue.isEmpty()) return; Graceful exit: finish everything queued first.
    try { task.run(); } catch (Throwable t) A task exception must never kill the worker. (ThreadPoolExecutor replaces dead workers instead.) FutureTask already captures exceptions, so this guards only raw Runnables.

    submit, shutdown, termination¶

        public <T> Future<T> submit(Callable<T> callable) {
        FutureTask<T> task = new FutureTask<>(callable);
        synchronized (stateLock) {                     // see "the shutdown race" in the docs
            if (shutdown) throw new RejectedExecutionException("pool is shut down");
            if (!queue.offer(task)) throw new RejectedExecutionException("queue full");  // AbortPolicy
        }
        return task;
    }

    public void shutdown() {
        synchronized (stateLock) { shutdown = true; }  // after this no task can be enqueued
    }

    public List<Runnable> shutdownNow() {
        shutdown();
        List<Runnable> pending = new ArrayList<>();
        queue.drainTo(pending);
        workers.forEach(Thread::interrupt);
        return pending;
    }

    public boolean awaitTermination(long timeout, TimeUnit unit) throws InterruptedException {
        long deadline = System.nanoTime() + unit.toNanos(timeout);
        for (Thread w : workers) {
            long left = deadline - System.nanoTime();
            if (left <= 0 || !w.join(java.time.Duration.ofNanos(left))) return false;
        }
        return true;
    }

    @Override
    public void close() throws InterruptedException {
        shutdown();
        if (!awaitTermination(30, TimeUnit.SECONDS)) shutdownNow();
    }
    Code Why
    new FutureTask<>(callable) FutureTask is both a Runnable (for the worker) and a Future (for the caller). It stores the result or the exception, which get() rethrows as an ExecutionException.
    synchronized (stateLock) { check shutdown; offer } Makes "is it open? then enqueue" atomic with respect to shutdown(). See the race below.
    queue.offer(task) → false ⇒ reject The bounded queue gives backpressure. offer doesn't block, so holding stateLock while calling it is fine.
    shutdownNow(): drainTo + interrupt Returns the never-started tasks to the caller, like the JDK does.
    awaitTermination uses Thread.join(Duration) It shares one deadline across all workers (JDK 19+ join returns a boolean).

    The shutdown race (the question that separates seniors)¶

    Without stateLock, this interleaving loses a task forever:

    sequenceDiagram participant S as submit() participant P as shutdown() participant W as last worker S->>S: reads shutdown == false ✔ P->>P: shutdown = true W->>W: shutdown && queue.isEmpty() → exits S->>S: queue.offer(task) ✔ ← nobody will ever run it, so future.get() hangs

    With stateLock, shutdown = true can't happen between the check and the offer. So either the task is enqueued before shutdown (and a worker will drain it, because workers only exit when the queue is empty), or the submit is rejected. ThreadPoolExecutor solves the same problem with a single atomic ctl word that packs the run state and worker count together.

    Run it¶

    failure captured in Future: java.lang.IllegalStateException: boom
500 tasks ok (sum of squares=41541750), queue-full rejection=true, post-shutdown rejection=true
PASS

    Common mistakes¶

    • Workers blocked in take() forever: the pool never shuts down.
    • Letting a task's exception propagate out of the worker loop: the pool silently shrinks.
    • An unbounded queue: OOM under load, and rejection never happens.
    • shutdown that isn't volatile or synchronized: workers may never see it.

    Follow-up questions¶

    How does ThreadPoolExecutor grow from core to max size?

    It adds core threads first, then queues, and only starts extra threads up to max when the queue is full. Then it rejects. See Executors.

    How would you add a CallerRuns policy?

    When offer fails, run task.run() on the submitting thread. That naturally slows the producer down.

    Why not just use virtual threads?

    For IO-bound tasks you would: Executors.newVirtualThreadPerTaskExecutor() + a Semaphore. A fixed pool remains right for CPU-bound work, sized to the core count.

    Full source: SimpleThreadPool.java 
    import java.util.ArrayList;
import java.util.List;
import java.util.concurrent.ArrayBlockingQueue;
import java.util.concurrent.BlockingQueue;
import java.util.concurrent.Callable;
import java.util.concurrent.Future;
import java.util.concurrent.FutureTask;
import java.util.concurrent.RejectedExecutionException;
import java.util.concurrent.TimeUnit;
import java.util.concurrent.atomic.AtomicInteger;

/**
 * Build a fixed-size thread pool: bounded queue, Future results, rejection, graceful shutdown.
 * Run: java SimpleThreadPool.java
 */
public class SimpleThreadPool implements AutoCloseable {

    private final BlockingQueue<Runnable> queue;
    private final List<Thread> workers = new ArrayList<>();
    private final Object stateLock = new Object();    // makes "check shutdown + enqueue" atomic
    private volatile boolean shutdown;

    public SimpleThreadPool(int threads, int queueCapacity) {
        queue = new ArrayBlockingQueue<>(queueCapacity);
        for (int i = 0; i < threads; i++) {
            workers.add(Thread.ofPlatform().name("pool-worker-", i).start(this::workerLoop));
        }
    }

    private void workerLoop() {
        while (true) {
            Runnable task;
            try {
                task = queue.poll(50, TimeUnit.MILLISECONDS);
            } catch (InterruptedException e) {
                return;                                // shutdownNow(): stop immediately
            }
            if (task == null) {
                if (shutdown && queue.isEmpty()) return;  // drained and no more submissions → exit
                continue;
            }
            try {
                task.run();                            // FutureTask captures exceptions into the Future
            } catch (Throwable t) {
                // a bare Runnable threw: keep the worker alive (a real pool would log this)
            }
        }
    }

    public <T> Future<T> submit(Callable<T> callable) {
        FutureTask<T> task = new FutureTask<>(callable);
        synchronized (stateLock) {                     // see "the shutdown race" in the docs
            if (shutdown) throw new RejectedExecutionException("pool is shut down");
            if (!queue.offer(task)) throw new RejectedExecutionException("queue full");  // AbortPolicy
        }
        return task;
    }

    public void shutdown() {
        synchronized (stateLock) { shutdown = true; }  // after this no task can be enqueued
    }

    public List<Runnable> shutdownNow() {
        shutdown();
        List<Runnable> pending = new ArrayList<>();
        queue.drainTo(pending);
        workers.forEach(Thread::interrupt);
        return pending;
    }

    public boolean awaitTermination(long timeout, TimeUnit unit) throws InterruptedException {
        long deadline = System.nanoTime() + unit.toNanos(timeout);
        for (Thread w : workers) {
            long left = deadline - System.nanoTime();
            if (left <= 0 || !w.join(java.time.Duration.ofNanos(left))) return false;
        }
        return true;
    }

    @Override
    public void close() throws InterruptedException {
        shutdown();
        if (!awaitTermination(30, TimeUnit.SECONDS)) shutdownNow();
    }

    public static void main(String[] args) throws Exception {
        AtomicInteger ran = new AtomicInteger();
        List<Future<Integer>> results = new ArrayList<>();
        try (var pool = new SimpleThreadPool(4, 1_000)) {
            for (int i = 0; i < 500; i++) {
                int n = i;
                results.add(pool.submit(() -> { ran.incrementAndGet(); return n * n; }));
            }
            Future<Integer> failing = pool.submit(() -> { throw new IllegalStateException("boom"); });
            try { failing.get(); throw new AssertionError("expected failure"); }
            catch (java.util.concurrent.ExecutionException e) { System.out.println("failure captured in Future: " + e.getCause()); }
        }
        long sum = 0;
        for (Future<Integer> f : results) sum += f.get();
        long expected = 0; for (int i = 0; i < 500; i++) expected += (long) i * i;
        if (sum != expected || ran.get() != 500) throw new AssertionError(sum + " " + ran);

        var tiny = new SimpleThreadPool(1, 1);
        tiny.submit(() -> { Thread.sleep(200); return 0; });
        Thread.sleep(20);                                   // worker picks the first task
        tiny.submit(() -> 1);                               // fills the queue (capacity 1)
        boolean rejected = false;
        try { tiny.submit(() -> 2); } catch (RejectedExecutionException e) { rejected = true; }
        tiny.close();
        boolean rejectedAfterShutdown = false;
        try { tiny.submit(() -> 3); } catch (RejectedExecutionException e) { rejectedAfterShutdown = true; }
        System.out.printf("500 tasks ok (sum of squares=%d), queue-full rejection=%s, post-shutdown rejection=%s%n",
                sum, rejected, rejectedAfterShutdown);
        if (!rejected || !rejectedAfterShutdown) throw new AssertionError();
        System.out.println("PASS");
    }
}
