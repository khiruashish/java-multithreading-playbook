    19. Concurrent Web Crawler¶

    L3 ★★★ · virtual threads · Phaser · Semaphore · concurrent set · LeetCode 1242

    Problem¶

    Given a start URL and a fetch(url) → links function (slow, blocking), crawl every page on the same host. Fetch concurrently, never fetch a page twice, limit the total number of in-flight requests (and the number per host), and return when the crawl is complete.

    The hard parts are knowing when you're done (new work is discovered while you run) and doing dedup atomically.

    Architecture¶

    flowchart LR S[start URL] --> SUB{visited.add&#40;url&#41;?} SUB -->|false: already seen| DROP[skip] SUB -->|true| REG[phaser.register&#40;&#41;] REG --> VT[new virtual thread] VT --> G{{global Semaphore 64}} G --> H{{per-host Semaphore}} H --> F[fetch&#40;url&#41; — blocking IO] F --> LINKS[for each same-host link → submit] LINKS --> SUB F --> DONE[phaser.arriveAndDeregister&#40;&#41;]
    sequenceDiagram participant C as caller (party 1) participant P as Phaser participant V1 as VT page 0 participant V2 as VT page 7 C->>P: new Phaser(1) C->>P: register (page 0) → parties=2 C->>P: arriveAndAwaitAdvance() … waits V1->>P: register (page 7) → parties=3 V1->>P: arriveAndDeregister (page 0 done) → parties=2 V2->>P: arriveAndDeregister (page 7 done) → parties=1 P-->>C: all parties arrived → advance → crawl complete

    Code walkthrough¶

        private final Fetcher fetcher;
    private final Set<String> visited = ConcurrentHashMap.newKeySet();      // atomic "claim this URL"
    private final Semaphore globalInFlight;                                 // protects us and the network
    private final Map<String, Semaphore> perHost = new ConcurrentHashMap<>();
    private final int perHostLimit;
    private final AtomicInteger peakInFlight = new AtomicInteger();
    private final AtomicInteger inFlight = new AtomicInteger();

    ConcurrentWebCrawler(Fetcher fetcher, int maxInFlight, int perHostLimit) {
        this.fetcher = fetcher;
        this.globalInFlight = new Semaphore(maxInFlight);
        this.perHostLimit = perHostLimit;
    }

    Set<String> crawl(String startUrl) {
        Phaser pending = new Phaser(1);                    // party #1 = the caller
        try (ExecutorService ex = Executors.newVirtualThreadPerTaskExecutor()) {
            submit(startUrl, ex, pending);
            pending.arriveAndAwaitAdvance();               // returns when every registered page has arrived
        }
        return visited;
    }

    private void submit(String url, ExecutorService ex, Phaser pending) {
        if (!visited.add(url)) return;                     // someone else already claimed it
        pending.register();                                // one more page in flight (BEFORE submitting!)
        ex.submit(() -> {
            try {
                for (String link : fetch(url)) {
                    if (host(link).equals(host(url))) submit(link, ex, pending);   // stay on the start host
                }
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            } finally {
                pending.arriveAndDeregister();             // this page is done
            }
        });
    }

    private List<String> fetch(String url) throws InterruptedException {
        Semaphore host = perHost.computeIfAbsent(host(url), h -> new Semaphore(perHostLimit));
        globalInFlight.acquire();
        try {
            host.acquire();
            try {
                peakInFlight.accumulateAndGet(inFlight.incrementAndGet(), Math::max);
                return fetcher.links(url);                 // blocking IO: the virtual thread parks
            } finally {
                inFlight.decrementAndGet();
                host.release();
            }
        } finally {
            globalInFlight.release();
        }
    }

    static String host(String url) { return url.split("/")[2]; }
    Code Why
    ConcurrentHashMap.newKeySet() + visited.add(url) add returns true for exactly one thread, so it's an atomic claim. "contains then add" would be a race that fetches pages twice.
    new Phaser(1) Party #1 is the caller. Each in-flight page is one more party.
    pending.register() before ex.submit(...) Crucial ordering. If the task were submitted first, it could finish and deregister before being registered, and the phase could advance early, so you'd return with work still running.
    arriveAndDeregister() in finally Every page arrives exactly once, even when fetch throws. Without the finally, a failure would hang the crawl.
    arriveAndAwaitAdvance() by the caller Returns when all registered parties have arrived: the dynamic version of CountDownLatch, which doesn't need to know the count up front.
    Global then per-host Semaphore The global limit protects us (sockets, memory). The per-host limit is politeness toward each site. Release in reverse order in finally.
    One virtual thread per page Fetching is blocking IO, so a VT parks for free. 2,000 pages means 2,000 cheap threads, with the concurrency limited by the semaphore.

    Phaser limit

    A Phaser supports up to 65,535 registered parties at once. For bigger crawls use a tiered phaser tree, or an AtomicInteger in-flight counter + CountDownLatch(1) released when the counter reaches zero.

    Run it¶

    crawled 1952 pages in 361 ms (sequential would be ~19520 ms), peak in-flight=64 (limit 64)
PASS

    The test computes the expected reachable set with a plain sequential DFS and checks that the crawler found exactly that set, without exceeding the in-flight limit.

    Java 8 version: what was harder¶

    • A fixed ThreadPoolExecutor(64) had to be both the concurrency limit and the thread budget.
    • Completion detection needed an AtomicInteger pending + CountDownLatch, or a CompletableFuture graph.
    • Blocking fetches inside a 64-thread pool limited throughput to 64 / latency. That's the same here, but here the semaphore can be raised to 1,000 without 1,000 OS threads.
    How would you add a depth limit or URL priority?

    Carry depth with each URL and skip when it's above the limit. For priority, put URLs into a PriorityBlockingQueue frontier consumed by N worker VTs instead of spawning a VT per URL.

    Distributed crawl?

    Partition URLs by host hash across workers (which keeps politeness local), keep a shared seen-set (a Bloom filter + store), and use a durable frontier (Kafka or a DB) with checkpointing.

    Full source: ConcurrentWebCrawler.java 
    import java.time.Duration;
import java.util.ArrayList;
import java.util.HashMap;
import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.Random;
import java.util.Set;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;
import java.util.concurrent.Phaser;
import java.util.concurrent.Semaphore;
import java.util.concurrent.atomic.AtomicInteger;

/**
 * LeetCode 1242 (web crawler multithreaded), production-flavoured: one virtual thread per page, a global limit on
 * in-flight fetches, a per-host politeness limit, a concurrent visited set, and a Phaser to know when we're done.
 * The "internet" is a simulated link graph where each fetch sleeps 5-15 ms.
 * Run: java ConcurrentWebCrawler.java
 */
public class ConcurrentWebCrawler {

    interface Fetcher { List<String> links(String url) throws InterruptedException; }

    private final Fetcher fetcher;
    private final Set<String> visited = ConcurrentHashMap.newKeySet();      // atomic "claim this URL"
    private final Semaphore globalInFlight;                                 // protects us and the network
    private final Map<String, Semaphore> perHost = new ConcurrentHashMap<>();
    private final int perHostLimit;
    private final AtomicInteger peakInFlight = new AtomicInteger();
    private final AtomicInteger inFlight = new AtomicInteger();

    ConcurrentWebCrawler(Fetcher fetcher, int maxInFlight, int perHostLimit) {
        this.fetcher = fetcher;
        this.globalInFlight = new Semaphore(maxInFlight);
        this.perHostLimit = perHostLimit;
    }

    Set<String> crawl(String startUrl) {
        Phaser pending = new Phaser(1);                    // party #1 = the caller
        try (ExecutorService ex = Executors.newVirtualThreadPerTaskExecutor()) {
            submit(startUrl, ex, pending);
            pending.arriveAndAwaitAdvance();               // returns when every registered page has arrived
        }
        return visited;
    }

    private void submit(String url, ExecutorService ex, Phaser pending) {
        if (!visited.add(url)) return;                     // someone else already claimed it
        pending.register();                                // one more page in flight (BEFORE submitting!)
        ex.submit(() -> {
            try {
                for (String link : fetch(url)) {
                    if (host(link).equals(host(url))) submit(link, ex, pending);   // stay on the start host
                }
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            } finally {
                pending.arriveAndDeregister();             // this page is done
            }
        });
    }

    private List<String> fetch(String url) throws InterruptedException {
        Semaphore host = perHost.computeIfAbsent(host(url), h -> new Semaphore(perHostLimit));
        globalInFlight.acquire();
        try {
            host.acquire();
            try {
                peakInFlight.accumulateAndGet(inFlight.incrementAndGet(), Math::max);
                return fetcher.links(url);                 // blocking IO: the virtual thread parks
            } finally {
                inFlight.decrementAndGet();
                host.release();
            }
        } finally {
            globalInFlight.release();
        }
    }

    static String host(String url) { return url.split("/")[2]; }

    public static void main(String[] args) {
        int pages = 2_000;
        Random rnd = new Random(42);
        Map<String, List<String>> graph = new HashMap<>();
        for (int i = 0; i < pages; i++) {
            List<String> out = new ArrayList<>();
            for (int k = 0; k < 4; k++) out.add("http://shop.test/p/" + rnd.nextInt(pages));
            out.add("http://other.test/p/" + i);           // off-host links must be ignored
            graph.put("http://shop.test/p/" + i, out);
        }
        Fetcher fetcher = url -> {
            Thread.sleep(Duration.ofMillis(5 + Math.floorMod(url.hashCode(), 11)));   // 5-15 ms of "network"
            return graph.getOrDefault(url, List.of());
        };

        // expected = everything reachable from page 0 (plain BFS)
        Set<String> expected = new HashSet<>();
        var stack = new ArrayList<String>(List.of("http://shop.test/p/0"));
        while (!stack.isEmpty()) {
            String u = stack.removeLast();
            if (!expected.add(u)) continue;
            for (String l : graph.getOrDefault(u, List.of())) if (host(l).equals("shop.test")) stack.add(l);
        }

        var crawler = new ConcurrentWebCrawler(fetcher, 64, 64);
        long t0 = System.nanoTime();
        Set<String> found = crawler.crawl("http://shop.test/p/0");
        long ms = (System.nanoTime() - t0) / 1_000_000;
        System.out.printf("crawled %d pages in %d ms (sequential would be ~%d ms), peak in-flight=%d (limit 64)%n",
                found.size(), ms, found.size() * 10, crawler.peakInFlight.get());
        if (!found.equals(expected) || crawler.peakInFlight.get() > 64) throw new AssertionError();
        System.out.println("PASS");
    }
}
