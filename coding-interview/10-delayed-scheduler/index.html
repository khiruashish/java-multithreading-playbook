    10. Delayed Task Scheduler¶

    L3 ★★★ · PriorityQueue · Condition.awaitNanos

    Problem¶

    Implement schedule(task, delay). Tasks must run as close as possible to their due time, in due-time order. A task scheduled later with a shorter delay must still run first. Don't use ScheduledExecutorService or DelayQueue.

    Key idea¶

    • A min-heap (PriorityQueue) ordered by due time gives the next task in O(1), and insertion costs O(log n).
    • One dispatcher thread sleeps exactly until the head is due, using awaitNanos(head.due - now).
    • When schedule() inserts a task that becomes the new head, it signals the dispatcher so it can recompute a shorter sleep. This is the important part.
    • Due tasks run on virtual threads, so a slow task never delays the next one.

    Code walkthrough¶

    Data structures¶

        private record Job(long dueNanos, long seq, Runnable task) implements Comparable<Job> {
        public int compareTo(Job o) {
            int c = Long.compare(dueNanos, o.dueNanos);
            return c != 0 ? c : Long.compare(seq, o.seq);      // FIFO for equal due times
        }
    }

    private final PriorityQueue<Job> queue = new PriorityQueue<>();   // min-heap by due time, guarded by lock
    private final ReentrantLock lock = new ReentrantLock();
    private final Condition changed = lock.newCondition();           // "new head or shutdown"
    private final AtomicLong seq = new AtomicLong();
    private final Thread dispatcher;
    private boolean shutdown;                                        // guarded by lock

    public DelayedTaskScheduler() {
        dispatcher = Thread.ofPlatform().name("scheduler-dispatcher").daemon(true).start(this::dispatchLoop);
    }
    • Job is a record with compareTo by dueNanos, then by a sequence number, so tasks with equal due times run FIFO (a PriorityQueue isn't stable by itself).
    • System.nanoTime(), not currentTimeMillis(): it's monotonic and unaffected by wall-clock adjustments.

    schedule()¶

        public void schedule(Runnable task, long delay, TimeUnit unit) {
        Job job = new Job(System.nanoTime() + unit.toNanos(delay), seq.getAndIncrement(), task);
        lock.lock();
        try {
            if (shutdown) throw new IllegalStateException("scheduler is shut down");
            queue.add(job);
            if (queue.peek() == job) changed.signal();   // new earliest job → dispatcher must re-compute its sleep
        } finally {
            lock.unlock();
        }
    }

    if (queue.peek() == job) changed.signal(); means we only wake the dispatcher if the new job is now the earliest. Otherwise the dispatcher's current sleep is already correct.

    The dispatcher¶

        private void dispatchLoop() {
        while (true) {
            Job due;
            lock.lock();
            try {
                while (true) {
                    if (shutdown) return;
                    Job head = queue.peek();
                    if (head == null) {
                        changed.await();                              // nothing scheduled: sleep until schedule()
                        continue;
                    }
                    long wait = head.dueNanos() - System.nanoTime();
                    if (wait <= 0) {
                        due = queue.poll();                           // it's time
                        break;
                    }
                    changed.awaitNanos(wait);                         // sleep until due, or until a new head arrives
                }
            } catch (InterruptedException e) {
                return;
            } finally {
                lock.unlock();
            }
            Thread.ofVirtual().start(due.task());                     // never run user code on the dispatcher
        }
    }

    @Override
    public void close() {
        lock.lock();
        try { shutdown = true; changed.signal(); } finally { lock.unlock(); }
    }
    Code Why
    changed.await() when empty No busy waiting. It sleeps until something is scheduled.
    changed.awaitNanos(wait) Sleeps until the head is due, or until signalled about a new head, or spuriously. In every case, loop and recompute.
    due = queue.poll(); break; then unlock Take the job out under the lock, but run it outside the lock.
    Thread.ofVirtual().start(due.task()) User code never runs on the dispatcher: a slow or failing task can't delay the others.

    Run it¶

    execution order: [A@100, B@150, C@300, D@450, E@500] finished after 502 ms
PASS

    B was scheduled 50 ms after A, C, and E, yet it ran in the correct place.

    Follow-up questions¶

    How does ScheduledThreadPoolExecutor / DelayQueue do it?

    The same way: a heap plus a Condition with awaitNanos. They also add a leader thread (the Leader-Follower pattern): only one thread waits timed for the head, while the others wait indefinitely. That avoids many threads all waking at the same deadline.

    Add fixed-rate repetition.

    After running, re-insert the job with due += period. Use the previous due time, not now, to avoid drift. Catch exceptions so one failure doesn't silently cancel future runs.

    What about millions of timers?

    A heap costs O(log n) per operation. Hashed or hierarchical timing wheels (Netty HashedWheelTimer, Kafka) give O(1) inserts at some cost in precision.

    Durability?

    In-memory timers die with the process. Use DB-backed schedulers (Quartz, SKIP LOCKED polling) for anything that must survive restarts.

    Full source: DelayedTaskScheduler.java 
    import java.util.ArrayList;
import java.util.Collections;
import java.util.List;
import java.util.PriorityQueue;
import java.util.concurrent.CountDownLatch;
import java.util.concurrent.TimeUnit;
import java.util.concurrent.atomic.AtomicLong;
import java.util.concurrent.locks.Condition;
import java.util.concurrent.locks.ReentrantLock;

/**
 * Build a mini ScheduledExecutorService: schedule(task, delay). One dispatcher thread sleeps exactly until the
 * earliest task is due, and wakes early if an even earlier task is scheduled. Due tasks run on virtual threads.
 * Run: java DelayedTaskScheduler.java
 */
public class DelayedTaskScheduler implements AutoCloseable {

    private record Job(long dueNanos, long seq, Runnable task) implements Comparable<Job> {
        public int compareTo(Job o) {
            int c = Long.compare(dueNanos, o.dueNanos);
            return c != 0 ? c : Long.compare(seq, o.seq);      // FIFO for equal due times
        }
    }

    private final PriorityQueue<Job> queue = new PriorityQueue<>();   // min-heap by due time, guarded by lock
    private final ReentrantLock lock = new ReentrantLock();
    private final Condition changed = lock.newCondition();           // "new head or shutdown"
    private final AtomicLong seq = new AtomicLong();
    private final Thread dispatcher;
    private boolean shutdown;                                        // guarded by lock

    public DelayedTaskScheduler() {
        dispatcher = Thread.ofPlatform().name("scheduler-dispatcher").daemon(true).start(this::dispatchLoop);
    }

    public void schedule(Runnable task, long delay, TimeUnit unit) {
        Job job = new Job(System.nanoTime() + unit.toNanos(delay), seq.getAndIncrement(), task);
        lock.lock();
        try {
            if (shutdown) throw new IllegalStateException("scheduler is shut down");
            queue.add(job);
            if (queue.peek() == job) changed.signal();   // new earliest job → dispatcher must re-compute its sleep
        } finally {
            lock.unlock();
        }
    }

    private void dispatchLoop() {
        while (true) {
            Job due;
            lock.lock();
            try {
                while (true) {
                    if (shutdown) return;
                    Job head = queue.peek();
                    if (head == null) {
                        changed.await();                              // nothing scheduled: sleep until schedule()
                        continue;
                    }
                    long wait = head.dueNanos() - System.nanoTime();
                    if (wait <= 0) {
                        due = queue.poll();                           // it's time
                        break;
                    }
                    changed.awaitNanos(wait);                         // sleep until due, or until a new head arrives
                }
            } catch (InterruptedException e) {
                return;
            } finally {
                lock.unlock();
            }
            Thread.ofVirtual().start(due.task());                     // never run user code on the dispatcher
        }
    }

    @Override
    public void close() {
        lock.lock();
        try { shutdown = true; changed.signal(); } finally { lock.unlock(); }
    }

    public static void main(String[] args) throws Exception {
        List<String> order = Collections.synchronizedList(new ArrayList<>());
        CountDownLatch done = new CountDownLatch(5);
        long t0 = System.nanoTime();
        try (var s = new DelayedTaskScheduler()) {
            s.schedule(() -> { order.add("C@300"); done.countDown(); }, 300, TimeUnit.MILLISECONDS);
            s.schedule(() -> { order.add("A@100"); done.countDown(); }, 100, TimeUnit.MILLISECONDS);
            s.schedule(() -> { order.add("E@500"); done.countDown(); }, 500, TimeUnit.MILLISECONDS);
            Thread.sleep(50);
            s.schedule(() -> { order.add("B@150"); done.countDown(); }, 100, TimeUnit.MILLISECONDS); // new head mid-sleep
            s.schedule(() -> { order.add("D@450"); done.countDown(); }, 400, TimeUnit.MILLISECONDS);
            if (!done.await(2, TimeUnit.SECONDS)) throw new AssertionError("tasks did not run");
        }
        long ms = (System.nanoTime() - t0) / 1_000_000;
        System.out.println("execution order: " + order + " finished after " + ms + " ms");
        if (!order.equals(List.of("A@100", "B@150", "C@300", "D@450", "E@500"))) throw new AssertionError();
        System.out.println("PASS");
    }
}
